# Netflix Data Analysis (EDA) Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The main objective is to explore Netflix content, identify patterns, analyze distributions, and visualize insights through different charts.

## Project Objectives
- Analyze Netflix Movies and TV Shows.
- Identify missing values and duplicate records.
- Explore content distribution.
- Analyze movie and TV show release years.
- Identify the top 10 countries producing Netflix content.
- Explore popular genres and content ratings.
- Analyze movie durations and TV show seasons.

## Dataset Information
- Dataset: Netflix Movies and TV Shows
- Total Records: 8,807
- Total Columns: 12
- Movies: 6,131
- TV Shows: 2,676
- Duplicate Records: 0

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Run the Project

**Step 1:** Clone or download this repository.

**Step 2:** Install the required libraries.

```bash
pip install pandas numpy matplotlib seaborn
```

**Step 3:** Make sure `netflix_titles.csv` is in the project folder.

**Step 4:** Run the Python file.

```bash
python main.py
```

**Step 5:** View the generated charts inside the `output` folder.
